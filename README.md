# 3D House Viewer (Three.js)

## An interactive 3D web application built using **HTML, CSS, and JavaScript (Three.js)** that allows users to explore a 3D house model with UI controls and sidebar-based interactions.
## Live Demo
```
https://deploy-preview-4--projectshowcaseintrino.netlify.app
```
## Features
- 3D model rendering using Three.js
- Supports GLB/GLTF models
- Sidebar toggle UI for interaction
- Smooth camera navigation and scene controls
- Responsive layout with CSS

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Three.js
- GLB/GLTF Models

## Folder Structure
- `index.html` - Main entry file
- `css/` - Styling files
- `js/` - JavaScript logic and Three.js scripts
- `models/` - GLB/GLTF 3D models
- `images/` - UI assets and textures

## How to Run
1. Clone the repository:
```bash
git clone <repo-link>
```
## Use Python local server:
```
python -m http.server 8000
```

## Open in browser:
```
http://localhost:8000/
```
